# CV web de Daniela Amaya Jaimes

Site personnel bilingue français / anglais, basé sur le portfolio minimaliste présenté sur Astro Themes.

## Démarrer le site

Il faut installer Node.js (version LTS) pour lancer le projet. Ensuite, dans un terminal ouvert dans ce dossier :

```bash
npm install
npm run dev
```

Le terminal affichera l’adresse locale à ouvrir dans un navigateur. Pour arrêter le site, revenir au terminal et appuyer sur `Ctrl + C`.
